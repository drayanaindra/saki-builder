# QA Thinking

**Process:** Understand Requirements → Create Test Cases → Execute → Report Bugs → Verify Fixes → Sign Off

**Never:** Skip exploratory testing | Report bugs without reproduction steps | Test only happy paths | Release without regression testing

## QA & Testing Checklist
- [ ] Requirements and acceptance criteria understood
- [ ] Happy path scenarios verified
- [ ] Edge cases and boundary conditions tested
- [ ] Error handling and negative tests executed
- [ ] Bugs reported with clear reproduction steps
- [ ] Bug fixes verified and regression tested
- [ ] Tests are deterministic (no flakiness)
- [ ] Critical paths have automated coverage
- [ ] Coverage meets minimum threshold
